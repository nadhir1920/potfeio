PORTFOLIO PROFESSIONNEL — NADHIR JLASSI
=======================================

CONTENU DU DOSSIER
- index.html : structure et contenu du site
- style.css  : design, couleurs et mise en page responsive
- script.js  : menu mobile et affichage agrandi des images
- assets/    : photos, attestations, certificats et PDF original

OUVRIR LE SITE SUR VOTRE ORDINATEUR
1. Extraire le dossier ZIP.
2. Ouvrir index.html avec Chrome, Edge, Firefox ou Safari.
3. Garder index.html, style.css, script.js et le dossier assets ensemble.

METTRE LE SITE EN LIGNE
Vous pouvez importer le dossier du site dans un hébergement statique comme Netlify,
GitHub Pages ou un espace d'hébergement fourni par votre établissement.
Le site ne nécessite ni base de données, ni installation, ni dépendance externe.

PERSONNALISATION
- Modifier les textes dans index.html.
- Modifier les couleurs et les tailles dans style.css.
- Remplacer les images du dossier assets tout en conservant leur nom, ou mettre à jour
  les chemins correspondants dans index.html.
- Ajouter vos coordonnées professionnelles et les liens réels de vos profils avant la
  publication si vous souhaitez que les visiteurs puissent vous contacter directement.

REMARQUE
Les statistiques YouTube affichées proviennent de la capture qui figure dans le PDF fourni.
Elles sont indiquées comme des statistiques de la capture et peuvent ne pas être actuelles.
